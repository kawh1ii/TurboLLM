# 简历项目表述建议

**TurboLLM：基于 vLLM 的推理调度与 KV 预算管理原型**

- 基于 vLLM 0.32.0 扩展调度核心路径，实现逐请求 token 配额、执行耗时反馈和等待补偿；在前缀缓存命中后核算新增 KV 需求，维护在途请求的未来块预算。
- 对接完成、取消和抢占恢复生命周期，修正运行队列顺序影响抢占对象、历史输出重算误判为 decode 等自身实现边界，保留原生物理块与引用计数管理。
- 建立版本/源码散列锁定、21 项纯策略及测量回归、batch-invariant 模式下 33/33 严格输出对照和真实引擎配额/回收验证；在单卡 RTX 4090 上完成 3B/7B、共享前缀、8K、突发与高 KV 压力评估。

**使用限制：** 当前端到端数据未显示稳定超过原生或调优后的 vLLM，不填写性能提升倍数。源码和详细结果见 RESULTS.md。上述表述反映已实现内容，面试前应能够手工推演 policy.py，并解释源码接入与结果边界；不要把上游 kernel、PagedAttention 或物理内存管理表述为自行实现。
