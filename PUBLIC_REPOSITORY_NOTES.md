# Public Repository Notes

This directory is the sanitized portfolio version of TurboLLM.

The original experimental workspace remains separate.

Included:

- source code
- execution scripts
- documentation
- small structured result files

Excluded:

- model weights
- Python environments
- Hugging Face caches
- profiler trace dumps
- Nsight binary reports
- raw server logs
- compiled CUDA binaries
- credentials and proxy configuration

The experimental evidence boundary described in README.md
must be preserved when presenting results.
